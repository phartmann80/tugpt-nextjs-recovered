### Expect the FX nag

Preflight will warn that the ECB rate is stale: the seeded rate is
**1 EUR = 1.1578 USD, reference date 2026-09-02**. That is a warning, not a
blocker, by design (#72) — the rate and its date are stored on every converted
row, so staleness can only move an enforcement decision and can never corrupt
what was recorded.

## 5. New standing item: monthly ECB rate refresh

Beginning this deploy. Read the ECB daily reference feed, insert a new
`fx_rates` row for `EUR->USD` with its published reference date. Query current
state with `private.fx_rate_status()` — it returns each pair's rate, age and
stale flag, which is the thing to alert on rather than relying on someone
reading a `RAISE WARNING` in a worker log.

Note `R7`: two different rates for one pair on one date are refused, since that
would make an event's accounted cost depend on insert order.
